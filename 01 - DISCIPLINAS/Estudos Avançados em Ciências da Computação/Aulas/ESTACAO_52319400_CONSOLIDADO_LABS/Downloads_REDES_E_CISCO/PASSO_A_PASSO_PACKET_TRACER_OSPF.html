FASE 00 INTRODUCAO · ESCOPO DO PROJETO

Roteiro Definitivo: Cisco Packet Tracer

Guia de execucao prática, passo a passo e porta a porta para implantacao da topologia OSPFv2 Multi-Área (Área 10 Filial e Área 0 Backbone). Inclui correcao estrutural de hardware, comandos Cisco IOS 15.x e aceites forenses.

01 WORKSPACE
Disposicao Física
Posicionamento de 3 Roteadores 2911, 2 Switches 2960 e 2 Estacoes de Trabalho no canvas.
02 LAYER 1 & 2
Cabeamento & Patch
Conexao de cada cabo direto e cruzado com resolucao do conflito de porta GigabitEthernet no R3.
03 ROUTING
CLI & OSPFv2 Multi-Área
Configuracao de R1 (ABR), R2 (Transit) e R3 (Matriz) com Router-IDs dedicados e wildcards exatos.
04 FORENSIC
Auditoria de Aceite
Ping de ponta a ponta (PC1 ao PC2), analise de saltos via traceroute e tabela de rotas OSPF.
Orientacao Operacional: Utilize as teclas de navegacao do teclado ou o dock inferior para percorrer cada etapa sequencialmente. Todos os blocos CLI possuem botao de copia instantanea para insercao direta no terminal do Cisco Packet Tracer.
PASSO 01 LAYER 0 · DISPOSITIVOS NO PACKET TRACER

Adicionar Dispositivos no Canvas

Abra o Cisco Packet Tracer e localize os dispositivos na barra inferior esquerda. Arraste e solte os 7 equipamentos necessarios em linha reta para facilitar a visualizacao da topologia.

1 3x ROTEADORES
Cisco 2911 ISR
1. Va em Network Devices (icone de roteador).
2. Selecione a subcategoria Routers.
3. Clique e arraste 3 unidades do modelo 2911 para o centro do palco.
4. Renomeie no canvas para R1, R2 e R3.
2 2x SWITCHES
Catalyst 2960-24TT
1. Na barra inferior, selecione Switches.
2. Arraste 2 unidades do modelo 2960-24TT.
3. Posicione um switch a esquerda de R1 (nomeie SW1) e outro a direita de R3 (nomeie SW2).
3 2x END DEVICES
PC-PT (Estacoes)
1. Va em End Devices (icone de computador).
2. Arraste 1 unidade de PC para a ponta esquerda (nomeie PC1).
3. Arraste outra unidade de PC para a ponta direita (nomeie PC2).
Disposicao Recomendada no Canvas (Esquerda para a Direita): TOPOLOGIA LINEAR
[ PC1 ] ——— [ SW1 ] ——— [ R1 ] ——— [ R2 ] ——— [ R3 ] ——— [ SW2 ] ——— [ PC2 ]
PASSO 02 LAYER 1 · CABEAMENTO FISICO E RETIFICACAO R3

Conexao de Cabos Porta a Porta

Selecione a ferramenta de conexoes (icone de raio). Utilize o cabo correto para cada segmento e aplique a retificacao obrigatoria de engenharia no Roteador R3 para eliminar o conflito de portas.

Origem (Dispositivo & Porta) Destino (Dispositivo & Porta) Tipo de Cabo no Packet Tracer Finalidade da Conexao
PC1 · FastEthernet0 SW1 · FastEthernet0/1 Copper Straight-Through (Direto) Acesso LAN Filial (192.168.10.0/24)
SW1 · GigabitEthernet0/1 R1 · GigabitEthernet0/1 Copper Straight-Through (Direto) Uplink Gateway Filial
R1 · GigabitEthernet0/0 R2 · GigabitEthernet0/0 Copper Cross-Over ou Direto WAN PTP R1-R2 (10.0.0.0/30) · Área 0
R2 · GigabitEthernet0/1 R3 · GigabitEthernet0/0 Copper Cross-Over ou Direto WAN PTP R2-R3 (10.0.0.4/30) · Área 0
R3 · GigabitEthernet0/1 PORTA CORRIGIDA SW2 · GigabitEthernet0/1 Copper Straight-Through (Direto) Uplink LAN Matriz (192.168.20.0/24)
SW2 · FastEthernet0/1 PC2 · FastEthernet0 Copper Straight-Through (Direto) Acesso Host Matriz
Atencao aos Triangulos Vermelhos:
No Packet Tracer, as portas dos roteadores iniciam em estado Administratively Down (triangulos vermelhos). Isso e normal. Elas ficarao verdes somente apos o comando no shutdown nas interfaces de cada roteador.
Por que GigabitEthernet 0/1 no R3?
O diagrama original duplicou G0/0 no R3 para o link WAN e para a LAN. Um roteador fisico Cisco 2911 possui interfaces independentes. Destinar G0/0 a WAN e G0/1 a LAN resolve a sobreposicao fisica.

PASSO 04 ROUTER CLI · R1 (AREA BORDER ROUTER)

Configuracao do Roteador R1

R1 interliga a Área 10 (Filial) ao Backbone (Área 0). Clique em R1, abra a aba CLI, digite no se surgir o dialogo inicial e cole o bloco de comandos abaixo.

Console Cisco IOS · R1 (Filial ABR)
! 1. Entrar no modo privilegiado e configuracao global enable configure terminal hostname R1 ! 2. Interface LAN (Conexao com Switch SW1 e PC1 na Area 10) interface GigabitEthernet0/1 ip address 192.168.10.1 255.255.255.0 no shutdown exit ! 3. Interface WAN PTP (Conexao com R2 no Backbone Area 0) interface GigabitEthernet0/0 ip address 10.0.0.1 255.255.255.252 no shutdown exit ! 4. Roteamento OSPFv2 Multi-Area router ospf 1 router-id 1.1.1.1 network 192.168.10.0 0.0.0.255 area 10 network 10.0.0.0 0.0.0.3 area 0 exit ! 5. Gravacao permanente na NVRAM end write memory
Compreensao dos Wildcards:
Para 192.168.10.0/24 o wildcard e 0.0.0.255.
Para o link PTP 10.0.0.0/30 (mascara 255.255.255.252), o wildcard e 0.0.0.3.
Resultado Esperado no Packet Tracer:
As luzes das interfaces G0/1 (com SW1) e G0/0 (com R2) comecarao a mudar para verde. O status de G0/0 completara quando R2 for ativado.
PASSO 05 ROUTER CLI · R2 (BACKBONE TRANSIT)

Configuracao do Roteador R2

R2 e o elemento central de trânsito no Backbone (Área 0). Possui duas interfaces WAN PTP (/30). Clique em R2, abra a aba CLI e aplique os comandos.

Console Cisco IOS · R2 (Backbone Transit)
! 1. Entrar no modo privilegiado e configuracao global enable configure terminal hostname R2 ! 2. Interface WAN PTP R1-R2 (10.0.0.0/30) interface GigabitEthernet0/0 ip address 10.0.0.2 255.255.255.252 no shutdown exit ! 3. Interface WAN PTP R2-R3 (10.0.0.4/30) interface GigabitEthernet0/1 ip address 10.0.0.5 255.255.255.252 no shutdown exit ! 4. Roteamento OSPFv2 (Ambas as sub-redes na Area 0) router ospf 1 router-id 2.2.2.2 network 10.0.0.0 0.0.0.3 area 0 network 10.0.0.4 0.0.0.3 area 0 exit ! 5. Gravacao na NVRAM end write memory
Mensagem de Sucesso Imediato no Terminal: ADJACENCIA R1-R2
%OSPF-5-ADJCHG: Process 1, Nbr 1.1.1.1 on GigabitEthernet0/0 from LOADING to FULL, Loading Done
Isso confirma que o roteador R1 e o roteador R2 trocaram pacotes Hello e seus Database Descriptors (DBD) estao 100% sincronizados.
PASSO 06 ROUTER CLI · R3 (GATEWAY MATRIZ)

Configuracao do Roteador R3

R3 fecha o Backbone e atende a LAN da Matriz (192.168.20.0/24). Lembre-se da particao de interfaces: G0/0 para a WAN e G0/1 para a LAN. Abra a aba CLI do R3.

Console Cisco IOS · R3 (Gateway Matriz)
! 1. Entrar no modo privilegiado e configuracao global enable configure terminal hostname R3 ! 2. Interface WAN PTP R2-R3 (10.0.0.4/30) interface GigabitEthernet0/0 ip address 10.0.0.6 255.255.255.252 no shutdown exit ! 3. Interface LAN Matriz (GigabitEthernet0/1 corrigida) interface GigabitEthernet0/1 ip address 192.168.20.1 255.255.255.0 no shutdown exit ! 4. Roteamento OSPFv2 (Ambas no escopo da Area 0) router ospf 1 router-id 3.3.3.3 network 10.0.0.4 0.0.0.3 area 0 network 192.168.20.0 0.0.0.255 area 0 exit ! 5. Gravacao permanente na NVRAM end write memory
Adjacencia R2-R3 Disparada:
%OSPF-5-ADJCHG: Process 1, Nbr 2.2.2.2 on GigabitEthernet0/0 from LOADING to FULL, Loading Done
Salvamento na Memoria:
O comando write memory copia o running-config da RAM para o startup-config da NVRAM, impedindo perda de dados se o roteador reiniciar.

PASSO 08 VERIFICACAO · TESTE DE PING E TRACERT

Validacao no Command Prompt (PC1)

Clique no PC1, abra a aba Desktop e clique em Command Prompt. Execute os comandos de teste sequenciais para validar a conectividade de ponta a ponta.

PC1 · Command Prompt (Aceite Forense)
PC> ping 192.168.10.1 Pinging 192.168.10.1 with 32 bytes of data: Reply from 192.168.10.1: bytes=32 time<1ms TTL=255 Ping statistics: Packets: Sent = 4, Received = 4, Lost = 0 (0% loss) PC> ping 192.168.20.10 Pinging 192.168.20.10 with 32 bytes of data: Request timed out. ! Normal no primeiro pacote devido a resolucao ARP Reply from 192.168.20.10: bytes=32 time=1ms TTL=125 Reply from 192.168.20.10: bytes=32 time=1ms TTL=125 Reply from 192.168.20.10: bytes=32 time=1ms TTL=125 Ping statistics: Packets: Sent = 4, Received = 3, Lost = 1 (25% loss) PC> tracert 192.168.20.10 Tracing route to 192.168.20.10 over a maximum of 30 hops: 1 <1 ms <1 ms <1 ms 192.168.10.1 (R1 LAN Gateway) 2 1 ms 1 ms 1 ms 10.0.0.2 (R2 WAN Entrada) 3 1 ms 1 ms 1 ms 10.0.0.6 (R3 WAN Entrada) 4 1 ms 1 ms 1 ms 192.168.20.10 (PC2 Destino Matriz) Trace complete.
Por que o primeiro 'Request timed out'?
Em redes Ethernet comutadas, o primeiro pacote ICMP e retido na fila enquanto o switch e o roteador transmitem quadros ARP Request para descobrir o endereco MAC do proximo salto. Ao repetir o ping, a taxa sera 100% de sucesso.
Analise do TTL = 125:
O Windows inicia o TTL em 128. O pacote atravessa 3 roteadores (R1, R2, R3). Cada roteador decrementa 1 unidade do campo TTL: 128 - 3 = 125. Prova forense de roteamento de camada 3 ativo.
PASSO 09 AUDITORIA CLI · COMANDOS FORENSES

Comandos de Inspecao nos Roteadores

Abra o terminal CLI de qualquer um dos roteadores para checar o estado das adjacencias OSPF e a presenca das rotas inter-area (identificadas pelo codigo O IA).

1. Tabela de Vizinhos NEIGHBOR
R1# show ip ospf neighbor

Neighbor ID: 2.2.2.2
Pri: 1
State: FULL/BDR
Interface: Gi0/0
Confirma que a adjacencia atingiu o estado estavel FULL.
2. Rotas Inter-Área IP ROUTE
R1# show ip route ospf

O IA 192.168.20.0/24
[110/3] via 10.0.0.2
Interface: Gi0/0
O IA significa rota inter-area aprendida pelo OSPFv2 com metrica acumulada.
3. Status de Interfaces IP INT BRIEF
R1# show ip int brief

Gi0/0: 10.0.0.1 (up/up)
Gi0/1: 192.168.10.1 (up/up)
Ambas as portas devem reportar Status UP e Protocol UP.
Comando Corretivo de Emergencia: Se você errar a digitacao de um Router-ID ou mascara, apos corrigir a configuracao digite no modo de comando: clear ip ospf process e confirme com yes para reiniciar as adjacencias instantaneamente.
