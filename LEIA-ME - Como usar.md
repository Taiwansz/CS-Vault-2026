# Como usar este Vault

1. No Obsidian, escolha **Open folder as vault / Abrir pasta como cofre** e selecione `Faculdade - 2026.2`.
2. Comece sempre por [[00 - Dashboard]].
3. Preencha professor, horários e notas na página principal de cada disciplina.
4. Para cada aula, crie uma nota dentro da pasta `Aulas` da disciplina e aplique `Template - Aula`.
5. Registre qualquer prazo como tarefa (`- [ ]`) e, se usar o plugin Tasks, acrescente uma data de vencimento.
6. Use `Avaliações 2026.2` como visão geral das provas e notas.
7. Não precisa instalar plugins para começar. **Templates** (core plugin) já melhora bastante o fluxo. Opcionalmente, instale **Tasks**, **Calendar** e **Dataview** depois.

## Padrão recomendado para nomes de aulas

`AAAA-MM-DD - Tema da aula`

Exemplo: `2026-08-10 - Análise Léxica`
